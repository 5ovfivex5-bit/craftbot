# Builds dataset (DATA-3, protocol 12.6)

`blueprints.json` holds 55 blueprints in three difficulty tiers. All blocks are items from the MineMind
palette (protocol 12.2). Generated by `tools/builds/`; do not hand-edit, rerun the scripts.

## Files
- `blueprints.json`: a JSON list of blueprint objects (ids 0..54, in order).
- `vanilla_converted.json`: intermediate output of `nbt2blueprint.py` (16 vanilla structures, with per-file mapping losses).
- `previews/<name>.png`: one layer-grid image per blueprint. Each Y layer is a top-down z-by-x grid,
  bottom layer on the left. Colours: planks tan, log brown, cobble grey, dirt brown, glass light blue, obsidian near-black.

## Schema (one blueprint)
| key | meaning |
|---|---|
| `id` | int, index in the list |
| `name` | unique string (the handmade names are exact: nether_portal, dirt_hut, cobble_house, wooden_house, watchtower, bridge, wall_segment, farm_plot) |
| `family` | shelter, house, tower, bridge, wall, portal, farm, decor |
| `tier` | 1, 2 or 3, by `block_count` (see tiers) |
| `size` | `[x, y, z]` |
| `palette` | single char -> item name. `.` is always air and is never in the palette |
| `layers` | bottom-up list over y. `layers[y][z]` is a string of length x (z row, x column) |
| `anchor` | `"bottom_center"`: bottom layer on the ground, footprint centred on the target cell |
| `required_items` | item -> count of blocks needed (recount of the layers) |
| `block_count` | total non-air cells |
| `source` | `handmade:<name>`, `vanilla:<jar path>`, or `variant:<base>:<op>` |
| `description` | short text |
| `vanilla_mapping_losses` | vanilla-sourced only: `unmapped_vanilla_blocks` (none in this set) and `dropped_non_structural` (vanilla block -> count of cells made air) |

## Tiers
| tier | blocks | count |
|---|---|---|
| 1 | 5-30 | 10 |
| 2 | 30-120 | 13 |
| 3 | 120-400 | 32 |

Tier 3 holds the larger vanilla houses and the x2 / mirror variants, so it is the largest tier.

## Sources
- **Handmade (12, `tools/builds/variants.py::handmade`)**: nether_portal (4x5x1 obsidian frame, 2x3 air inside),
  dirt_hut, dirt_hut_small, cobble_cottage, cobble_house, wooden_house, watchtower, bridge, wall_segment,
  farm_plot, farm_plot_large, well.
- **Vanilla (16, `tools/builds/nbt2blueprint.py`)**: village houses read straight from the jar
  `~/.gradle/caches/fabric-loom/26.2/minecraft-common.jar` (gzipped NBT, read with an in-house NBT reader):
  - plains: small_house_5, accessory_1, animal_pen_1, armorer_house_1, butcher_shop_1, masons_house_1
  - desert: small_house_5, fletcher_house_1, farm_1
  - savanna: small_house_5, medium_house_1
  - taiga: small_house_5, small_house_4, medium_house_1
  - snowy: small_house_7, armorer_house_1
  Paths are `data/minecraft/structure/village/<biome>/houses/<name>.nbt` inside the jar.
  Structures larger than 400 blocks were excluded (plains_medium_house_1 at 517).
- **Procedural variants (27, `tools/builds/variants.py::build`)**:
  - `__swap_material`: planks <-> cobblestone swapped (7 bases).
  - `__x2`: uniform 2x scale of simple shapes (wall_segment, farm_plot, well, dirt_hut_small). Kept only when tier stays in range.
  - `__mirror_x`: x-mirror of asymmetric bases (6) and of the converted vanilla houses (14). Symmetric results are dropped as duplicates.

## Palette mapping rules (`tools/builds/nbt2blueprint.py::_map_block`)
- Wood species collapse to oak: any log/wood/stem -> `oak_log`; any planks, stairs, slab, fence, fence gate, door, trapdoor, pressure plate, button -> `oak_planks`.
- Stone family (stone, cobble, bricks, andesite, diorite, granite, stairs, slabs, walls, mossy) -> `cobblestone`.
- Sand, sandstone, terracotta -> `sand`. Gravel -> `gravel`. Dirt, grass block, farmland, dirt path, clay -> `dirt`.
- Glass, glass panes, stained glass panes, ice -> `glass`. Obsidian -> `obsidian`. Furnace/smoker/blast furnace -> `furnace`. Chest/barrel -> `chest`. Crafting table -> `crafting_table`.
- Air / decor / non-structural -> air (not in the palette). This covers torches, lanterns, beds, carpets, wool,
  glazed terracotta, plants, flowers, potted plants, leaves, water, lava, snow, signs, banners, jigsaw, ladders, bells, lecterns, etc.
- Shape is flattened: stairs, slabs and fences become full cubes of the same material. Doors and trapdoors are solid (no openings).

Loss totals across the 16 vanilla structures (cells made air): wall_torch 48, jigsaw 35, snow 35, wheat 17,
short_grass 13, torch 10, large_fern 10, ladder 8, water 7, beds 20 (all colours), potted_cactus 4, lantern 4, other
plants/decor under 3 each. Shape detail (stairs, slabs, fences, doors) is not counted as loss; it is simplified to full blocks.

## Regenerate and validate
```
.venv/bin/python tools/builds/nbt2blueprint.py --dump      # palette survey of village structures
.venv/bin/python tools/builds/nbt2blueprint.py             # -> data/builds/vanilla_converted.json
.venv/bin/python tools/builds/variants.py                  # -> data/builds/blueprints.json
.venv/bin/python tools/builds/render_preview.py            # -> data/builds/previews/*.png
.venv/bin/python tools/builds/validate.py [--registry PATH]
```
`validate.py` checks: 30-60 entries, exact handmade names, ids, schema keys, layer/size shape, palette coverage,
block_count and required_items recount, tier ranges, family set, item names, and nether_portal geometry.

## Item-name status
`data/registry/items.json` (DATA-1) did not exist when this was built. `validate.py` therefore checks item names
against a fallback set of the 11 names used here (oak_log, oak_planks, cobblestone, dirt, sand, gravel, glass,
obsidian, furnace, crafting_table, chest). These are all v6 or vanilla-standard names. Re-run `validate.py` once
items.json lands; it reports any name not in the registry.
