# Tasks (DATA-2, PROTOCOL 12.5 + 12.8)

`tasks.json` is generated by `tools/tasks/gen_tasks.py` (edit the generator, then rerun) and checked by
`tools/tasks/validate.py` (`python3 -I tools/tasks/validate.py`). 64 tasks in 9 families.

## Schema
Top level is a list. Each task:
- `id` (snake_case, unique), `name`, `family`, `description`, `params`
- `success`: one predicate (ends the episode with success)
- `milestones`: list of `{predicate, reward}`; each pays once per episode. Reward is in (0, 0.5],
  and the sum of milestone rewards is kept below 1.0. Success is the task-level payoff.
- `max_steps`: decisions (5 decisions/s). E.g. 1500 = 5 min, 20000 = ~67 min.
- `prerequisites`: task ids that gate curriculum sampling (see DAG below).
- `start_kit` (optional): items given at episode start, used for late-stage tasks.
- `source`: vanilla advancement it is modeled on (`story/…`, `husbandry/…`, `adventure/…`, `nether/…`),
  or `none (...)` where no advancement applies.

Predicates are objects with `type` plus fields. Closed set (validator enforces):
`has_item {item,count}`, `crafted {item}`, `mined {block,count}`, `killed {mob,count}`,
`ate {food}` (name or `"any"`), `slept`, `survive_night`, `placed {block,count}`,
`build_complete {blueprint,min_progress}` (0 < min_progress <= 1), `portal_lit`, `in_dimension {dim}`
(`overworld`|`nether`), `reached_y {max_y}` (agent y <= max_y), `distance_travelled {n}`,
`health_above {n}`; social (12.8): `near_teammate {dist,steps}`, `look_at_teammate {count}`,
`crouch_greet {count}`, `follow_teammate {steps}`, `gave_item {count}`, `shared_chest {count}`,
`msg_near_teammate {count}`. No conjunctions: each success/milestone is one predicate.

## Families (count)
gather 8, tools 9, food 7, build 8, combat 7, survival 5, nether 10, explore 4, social 6.

## Curriculum
Curriculum roots (no prerequisites), 15 tasks: `gather_wood`, `build_dirt_hut`, `combat_kill_zombie`,
`explore_walk_100`, `food_hunt_cow`, `food_hunt_pig`, `food_hunt_sheep`, `food_hunt_chicken`,
`survival_eat_any`, and the social roots `social_crouch_greet`, `social_look_at_teammate`,
`social_stay_together`, `social_follow_teammate`, `social_chat_nearby`, `social_share_chest`.
Main chain: wood -> crafting table -> wooden pickaxe -> stone -> stone pickaxe -> furnace/iron ->
iron pickaxe -> diamond -> diamond pickaxe -> obsidian -> portal frame + flint and steel -> light portal
-> enter Nether -> Nether gathering, blaze, ghast, ancient debris.

Prerequisites gate sampling only (curriculum unlock by success EMA). An episode starts from scratch unless
`start_kit` is given, so a task like `nether_enter` runs the whole route from an empty inventory.

## Assumptions to confirm with CORE
- `reached_y` means "agent y <= max_y at least once".
- `distance_travelled` counts cumulative horizontal blocks since episode start (not per dimension);
  `explore_nether_walk` therefore relies on its `in_dimension` milestone for Nether specificity.
- Social rewards are small and milestones pay once; no social task has a prerequisite beyond roots.
- `build_complete` on blueprint names from `data/builds/blueprints.json` (DATA-3).

## Name sources
Items, blocks and mobs use vanilla names without `minecraft:`; wood species collapsed to `oak_*`.
Checked by `validate.py` against `data/registry/{items,blocks,mobs}.json` and
`data/builds/blueprints.json` when present (see validator output for the current status).
